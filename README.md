# PraiseFlow live demo

Static build of the PraiseFlow website template with fictional demo content, for https://jtechstudio2-png.github.io/praiseflow-demo.

This repository contains only the published website (HTML, CSS, JavaScript, fonts and images). The PraiseFlow source code is proprietary and sold separately on WiCareStore.

Deploy: any static host, serving this folder as the site root (no build step).
